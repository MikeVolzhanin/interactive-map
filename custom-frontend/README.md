# Кастомный фронтенд (interactive-map)

Сохранённая версия SPA: карта России, авторизация, онбординг, публичные новости НН ВШЭ.

Основной репозиторий можно обновлять с `master` (`git pull`); этот каталог **не перезаписывается** при обновлении, если вы его не удаляете.

## Запуск

```bash
cd custom-frontend
npm ci
npm run dev
```

По умолчанию Vite на порту **3000**, API проксируется на `http://localhost:8080` (нужен `applicants-service` из основного проекта) или HTML новостей через прокси в `vite.config.ts` на `nnov.hse.ru`.

## Сборка

```bash
npm run build
```

## Интеграция в основной `frontend/`

При необходимости можно перенести содержимое `src/app/` и `public/` в основной фронтенд репозитория или подключить этот пакет как отдельный сервис в docker-compose.
